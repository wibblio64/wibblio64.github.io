# wibblio64.github.io
This is the source code for my personal website, [wibblio64.github.io](https://wibblio64.github.io/).

This site runs on [Jekyll](https://jekyllrb.com/), an open-source static site generator built in Ruby.

## Local Testing

- `bundle exec jekyll build` will build the site locally.
- `bundle exec jekyll serve` will build the site locally, and then serve it at `http://127.0.0.1:4000/`.
- `bundle exec jekyll serve watch` will build the site locally, rebuild if changes occurs, and then serve it at `http://127.0.0.1:4000/`.
