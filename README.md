# wibblio64.github.io
This is the source code for my personal website, [wibblio64.github.io](https://wibblio64.github.io/).

It runs on [Next.js](https://nextjs.org/), a full-stack web framework built in TypeScript, and [Bun](https://bun.sh/), a fast, all-in-one JavaScript/TypeScript runtime. Both are open-source.

## Local Testing

- `bun dev` will start a local development server that gives you a live preview as you edit files.
- `bun build` will build the site locally into a deploy-ready production output.
