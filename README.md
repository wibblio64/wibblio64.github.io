# My website
This is the source code for my personal website, [wibblio64.github.io](https://wibblio64.github.io/).

This project utilizes [Eleventy](https://www.11ty.dev/), a static site generator built in JavaScript, [LiquidJS](https://liquidjs.com/), a template engine originally built in Ruby and ported to JavaScript, and [Bun](https://bun.sh/), an all-in-one JavaScript runtime; all three are open-source tools.
